# HO-27 / HO-28 Source HTML Archive

Status: Design- und Herkunftsarchiv, nicht Produktionsquelle.

Diese Dateien wurden am 17. Mai 2026 aus lokalen Downloads in das Repo
übernommen, damit die Herkunft der bildbasierten Handouts nachvollziehbar
bleibt:

- `schlaf_fruehwarnsystem.html` → Vorläufer zu `src/handouts/a9_schlaf_fruehwarnsystem.pdf`
- `hypervigilanz_erschoepfung.html` → Vorläufer zu `src/handouts/b11_hypervigilanz_erschoepfung.pdf`

## Einordnung

Die Dateien erklären sichtbar die Layout- und Inhaltsentwicklung von HO-27 und
HO-28. Sie sind aber **nicht** kanonische Produktionsdateien für neue Handouts.

Bekannte Abweichungen vom aktuellen Fachstelle-Workflow:

- Tabellenlayout statt semantischem Starter-Template.
- Inline-Styles und lokale Einzelregeln.
- Getönte Seiten-/Boxflächen, nicht konsequent `ink-light`.
- Footer- und Quellenlogik nicht vollständig nach aktueller Spec.
- Keine PDF/UA-Produktionskette.

Für neue oder zu migrierende Handouts gilt stattdessen:

- `docs/fachstelle-handout-workflow/fachstelle-handout-starter.html`
- `docs/HANDOUT_INVENTAR_UND_MIGRATIONSPLAN.md`
- `.agents/skills/fachstelle-handout/references/HANDOUT_TEMPLATE.md`

Diese Archivdateien dürfen als visuelle Referenz und Text-Herkunft gelesen
werden, aber nicht als Vorlage kopiert werden.
