# Changelog

## 0.3.0-draft - 2026-05-17

- Diagramm-Tokens auf `ink-light` getrimmt: weisser Grund, deutlich hellere Tints, keine vollflaechigen getoenten Diagrammtraeger.
- Ampel, Saeulen-Check, Quadranten und Eisberg auf Konturen/Linien statt grosser Farbfuellungen umgestellt.
- Phasenverlauf-Bands stark aufgehellt, damit Verlauf/Labels statt Hintergrundfarbe tragen.
- `DG_PRINT_POLICY` als Registry-Metadatum und Export ergaenzt.
- README und Freigabe-Checkliste um Druckoekonomie-Gate erweitert.

## 0.2.0-draft - 2026-05-17

- Fachstelle-Branding im Bibliotheks-Intro und HTML-Titel gesetzt.
- `DIAGRAM_REGISTRY` mit Status, Eignung, Krisenhinweisen, Alt-Text, Lesereihenfolge und Freigaberegel ergaenzt.
- `DIAGRAM_EXAMPLE_DATA` eingefuehrt, damit Beispiel-Daten von echten Handout-Daten getrennt sind.
- Generische Krisennummern aus dem Tacho-Default entfernt.
- SVG-IDs fuer Marker und Gradients eindeutig gemacht.
- Erste ARIA-/Metadaten-Schicht fuer Diagrammframes ergaenzt.
- README, Freigabe-Checkliste, Produktions-Rendering-Notiz und Accessibility-Notiz ergaenzt.

## 0.1.0-draft - vor 2026-05-17

- Erste Canvas-Version mit zehn Diagramm-Komponenten.
