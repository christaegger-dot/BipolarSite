# Altauslieferungen — Referenzstände (asymmetrisches Randmodell)

Diese Dateien stammen aus dem früheren asymmetrischen Randmodell
(12 mm / 14 mm / 11 mm / 14 mm; nutzbare Höhe 187 mm) und dienen
ausschliesslich als Referenzstände.

**Sie entsprechen nicht dem neuen 14-mm-Standard** (14/14/14/14; 182 mm Höhe),
der im Skill `querformat-handout-render` verbindlich definiert ist.
